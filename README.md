# HR Analytics SQL Project

## Project Overview
This project uses MySQL to analyze employee data and answer HR business questions about workforce composition, salary patterns, hiring trends, manager relationships, and employee attrition.

## Dataset
- `employees.csv` — employee IDs, names, job titles, salaries, hire dates, manager IDs, and employment status.
- `departments.csv` — department IDs and department names.

## Tools Used
- MySQL
- MySQL Workbench
- SQL

## Key Analysis
- Employee hiring trends by year
- Department-wise employee counts and average salaries
- Employees earning more than their managers
- Employees earning above their department's average salary
- Duplicate salary identification
- Employees without assigned managers
- Department-wise attrition rates
- Departments with the highest attrition rates

## SQL Concepts
SELECT, WHERE, GROUP BY, HAVING, JOINs, subqueries, CTEs, CASE expressions, and window functions.

## Business Objective
To demonstrate how SQL can help HR teams understand workforce composition, compensation, recruitment trends, and employee attrition.

## Note
This project uses fictional practice data. Some records contain intentional data-quality issues for analysis practice.
